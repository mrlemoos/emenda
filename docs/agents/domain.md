# Documentação de domínio

O Emenda usa contexto único.

Antes de explorar ou alterar o projeto, leia:

- `CONTEXT.md`, para o vocabulário do domínio;
- os ADRs relevantes em `docs/adr/`.

Use os termos do glossário em specs, issues, testes e código. Não substitua termos que o glossário manda evitar.

Se uma decisão contradisser um ADR, declare o conflito em vez de o sobrescrever silenciosamente.
