# Rótulos de triagem

| Papel da skill | Rótulo local | Uso |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação |
| `needs-info` | `needs-info` | Aguarda informação |
| `ready-for-agent` | `ready-for-agent` | Pronto para execução autónoma |
| `ready-for-human` | `ready-for-human` | Exige trabalho humano |
| `wontfix` | `wontfix` | Não será executado |

Quando uma skill citar um papel, use o rótulo local correspondente.
